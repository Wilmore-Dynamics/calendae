### // SPÉCIFICATIONS TECHNIQUES
* **Design System :** Sand Cream (#F5F5F3), Deep Black (#000000), Inter Typography.
* **Core :** Python.
* **Protocole :** CalDAV natif & Synchronisation Multi-device (iOS, Android, Desktop).
* **Auth :** Hybride (Native / OIDC - Keycloak & Authelia).

### // PHILOSOPHIE
> **Zéro Dette Technique.** > Calendae est bâti sur une architecture légère visant l'efficience maximale des ressources et l'interopérabilité totale via des standards ouverts.
